# ThunderbirdVidmova

Thunderbird WebExtension для автоматичного збору відмов постачальників.

## Потік
1. Плагін автоматично сканує відправлені листи.
2. Витягує з них позиції замовлення.
3. Зберігає назву, код Моріона та замовлену кількість локально.
4. Автоматично сканує вхідну пошту.
5. Визначає відповідь за threading, темою, відправником і часом.
6. Читає текст листа та підтримувані текстові вкладення.
7. Зіставляє назву тільки з позиціями відповідного замовлення.
8. Код Моріона завжди береться з початкового замовлення.
9. Рахує відмову як `замовлено - підтверджено`.
10. Накопичує актуальний список без повторної обробки листів.

## Статус
MVP development.

## Важливе
XLS/XLSX зараз потребують окремого binary parser. На цьому етапі їх не можна вважати повністю підтриманими - текстове читання вкладення не є коректним XLSX parsing.
