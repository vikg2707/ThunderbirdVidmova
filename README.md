# ThunderbirdVidmova

Thunderbird WebExtension для автоматичного збору відмов постачальників.

## MVP
- збереження відправлених замовлень;
- автоматичний моніторинг вхідної пошти;
- розбір plain text / HTML;
- XLSX / CSV / TXT вкладення;
- зіставлення товарів тільки з початковим замовленням;
- код Моріона береться тільки з початкового замовлення;
- повні та часткові відмови;
- накопичення актуального списку;
- захист від повторної обробки;
- копіювання результату;
- локальне зберігання без зовнішнього сервера.

## Статус
MVP foundation.
